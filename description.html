Algorithm Viewer: Run / Step for Flowcharts

Makes flowcharts created with tiny_algorithm interactive for readers, in pages, course summaries, forums and quiz text.

Features

  • Run / Step / Reset with the current block highlighted and a speed slider.
  • Console with input, variable watch and generated code (Python, C, Java, C#) beside the diagram.
  • Zoom buttons and Ctrl + mouse wheel.
  • Runs in the reader's browser: nothing is sent to the server.
  • Opt-in per diagram: only diagrams inserted with the Interactive option are replaced.

What's new in 0.4.0

  • Supports Moodle 4.5 LTS and 5.0 - 5.3 (tested on all of them).
  • Serbian Cyrillic language files; the viewer picks Latin or Cyrillic from the Moodle language.
  • Moodle coding standard (phpcs, ESLint, stylelint) and GitHub Actions with moodle-plugin-ci.

Requirements

  • Moodle 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • The tiny_algorithm plugin. After installing, switch the filter On in Site administration, Plugins, Filters, Manage filters.

Privacy

The program runs in the reader's browser and nothing is sent anywhere. Two display preferences (code and variable panels) are kept in the browser's local storage. The plugin implements the Moodle Privacy API (no personal data stored).
