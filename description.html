Algorithm Viewer: Run / Step for Flowcharts

Makes flowcharts created with tiny_algorithm interactive for readers, in pages, course summaries, forums and quiz text.

Live demo: try the plugin on algorithm.tsp.edu.rs. Log in as a guest, or use the demo accounts teacher and student (password Demo-2026). Everything is reset every night.

What's New in v2.5.1

  • Full screen: with tiny_algorithm 2.5.2 every interactive diagram has a full screen button in its corner; the diagram, the console, the variables and the code cover the screen, also on phones.
  • Cleaner toolbar: zoom sits in the corner of the diagram; Variables and Code are switches that show their state.
  • Input on phones: a check button and the Go key of the phone keyboard confirm a value.
  • Requires tiny_algorithm 2.5.1 or later.

Core features

  • Run / Step / Reset: the current block is highlighted, with a speed slider.
  • Console with input: variable watch and generated code beside the diagram: pseudo-code and eleven languages with tiny_algorithm 2.4 (Python, C, C++, Java, C#, JavaScript, Pascal, Visual Basic .NET, Go, Rust, Kotlin).
  • Zoom and full screen: buttons in the corner of the diagram, Ctrl + mouse wheel and two-finger pinch.
  • Runs in the reader's browser: nothing is sent to the server.
  • Opt-in per diagram: only diagrams inserted with the Interactive option are replaced.
  • Edit and test: when the teacher allows it, students edit their own copy and run the teacher's tests.

The algorithm plugins

  • Algorithm (flowchart): the flowchart editor in TinyMCE, with the interpreter and code generation.
  • Algorithm viewer (Run / Step) (this plugin): Run / Step for readers and the student features in any content.
  • Algorithm question type: quiz questions graded automatically with tests.

Requirements

  • Moodle: 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • tiny_algorithm: version 2.5.1 or newer (2.5.2 for full screen and input on phones). After installing, switch the filter On in Site administration, Plugins, Filters, Manage filters.

Privacy

The program runs in the reader's browser and nothing is sent anywhere. Two display preferences (code and variable panels) and the student's own copy of an editable diagram are kept in the browser's local storage. The plugin implements the Moodle Privacy API (no personal data stored).
